# ชุดเอกสาร ว804

ขอบเขตที่ผู้ใช้ยืนยัน: จัดทำและพิมพ์เอกสารก่อน **ยังไม่เชื่อมสายอนุมัติ**

## เมนูและข้อมูลร่วมกัน

- `/requests/w804?document=purchase` — รายงานขอซื้อและรายละเอียด TOR
- `/requests/w804?document=summary` — รายงานสรุปผลการจัดซื้อ
- `/requests/w804?document=settlement` — รายงานส่งใช้เงินยืม

เมนูเปิด–ปิดอยู่ใต้ ว119 สำหรับผู้ยื่นคำขอและผู้ดูแลระบบ หน้า server ตรวจบัญชีที่เปิดใช้งานด้วย
ทุกเมนูเป็น query ของหน้าเดียวกัน จึงเก็บข้อมูลชุดเดียวกันใน React state ระหว่างสลับเมนู
ไม่มีการสร้างคำขอ เลขที่เอกสารอัตโนมัติ งานอนุมัติ หรือการเขียนข้อมูลลง Supabase และไม่ต้องมี migration

## การบันทึกและการพิมพ์

- บันทึกแบบร่างเป็น `W804-draft.json` ลงเครื่องด้วยการกระทำของผู้ใช้ ไม่ใช้ localStorage
- เปิดไฟล์เดิมด้วย Zod schema รุ่น 1 ตรวจประเภท/วันที่/จำนวนรายการ/ขนาดไฟล์สูงสุด 250 KB
- แบบร่างเก็บข้อมูลทั้ง 3 รายงาน แต่ **ไม่เก็บไฟล์แนบ** ต้องเลือกไฟล์ใหม่หลังเปิดแบบร่าง
- พิมพ์และดาวน์โหลด A4 ใช้ TH SarabunPSK และตัวแบ่งหน้าร่วมของระบบ โดย TOR เริ่มหน้าใหม่
- ตรวจพื้นที่ตรามหาวิทยาลัย ชื่อหน่วยงาน ชื่อแบบฟอร์ม ข้อความท้ายกระดาษ และเลขหน้าก่อนดาวน์โหลด หากเบราว์เซอร์วาดบางส่วนหาย จะลองสร้างใหม่ไม่เกิน 3 ครั้ง แล้วแจ้งข้อผิดพลาดแทนส่งไฟล์ที่ไม่ครบ (เปิดตรวจเฉพาะ ว804 ไม่เปลี่ยนทางทำงานของแบบเดิม)
- ไฟล์แนบ PDF/JPG/PNG รวมท้ายเอกสารบนเครื่อง ไม่อัปโหลดไปยังเซิร์ฟเวอร์
- สถานะในเอกสารไม่ได้ยืนยันการอนุมัติ การจ่ายเงิน หรือการรับคืนเงิน ช่องความเห็น/ลายมือชื่อว่างไว้ให้ดำเนินการจริง

## กติกาข้อมูล

`model.ts` แยก schema การเก็บร่างออกจากการตรวจความครบถ้วนก่อนพิมพ์
วงเงินขอซื้อและวงเงินที่ได้รับความเห็นชอบต้องมากกว่า 0 และไม่เกิน 50,000 บาท
ราคาต่อหน่วยต้องรวมภาษี ค่าขนส่ง และค่าใช้จ่ายแล้ว ปัดเศษแต่ละรายการเป็นสตางค์ก่อนรวม
ยอดซื้อจริงไม่เกินวงเงินที่กรอกว่าได้รับความเห็นชอบ รายงานส่งใช้เงินยืมต้องมีเลขที่/วันที่สัญญา
และยอดใช้จริงไม่เกินเงินยืม หากเกินให้ตรวจสอบกับงานการเงิน ไม่พิมพ์ยอดคืนติดลบ
แยก “วงเงินที่ยังไม่ใช้” ออกจาก “เงินคงเหลือที่ขอส่งคืน” อย่างชัดเจน

เนื้อหาปรับจากภาพตัวอย่าง 4 ภาพของผู้ใช้เป็นคณะรัฐศาสตร์ มหาวิทยาลัยอุบลราชธานี
ไม่คัดลอกชื่อบุคคล ร้านค้า ยอดเงิน ตัวอย่างกิจกรรม หรือเงื่อนไขเฉพาะของเทศบาลมาเป็นค่าเริ่มต้น
อ้างอิงชื่อหนังสือและกรอบวงเงินจาก [เอกสารเผยแพร่ของ สพพ.](https://www.neda.or.th/2023/upload/download/file/file-1766658312698-Thai-657.pdf)
ช่อง TOR/ผู้ลงนามเป็นข้อมูลที่ผู้จัดทำต้องกำหนดตามข้อเท็จจริงและหลักเกณฑ์ของหน่วยงาน
